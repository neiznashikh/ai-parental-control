# Learn2Unlock AI

Android-приложение родительского контроля: блокирует выбранные приложения (игры, соцсети, YouTube), пока ребёнок не выполнит задания. Задания готовит и проверяет ИИ (Claude) под возраст, уровень, интересы и слабые места ребёнка.

## Типы заданий
- Математика, логика и знания
- Чтение вслух (распознавание речи)
- Пересказ голосом или текстом
- Набор текста, письмо
- Иностранный язык (казахский, английский)

Интерфейс и задания: русский, казахский, английский.

## Как получить APK
Каждая загрузка в ветку `main` запускает сборку в GitHub Actions. Готовый файл появляется в разделе **Releases** → `Learn2Unlock-AI.apk`.

## Устройство
- `android/app/src/main/kotlin/...` — служба блокировки (Accessibility), мост к интерфейсу, запросы к Claude API, распознавание речи
- `android/app/src/main/assets/www/` — интерфейс ребёнка и родителя (HTML/JS), логика заданий и адаптации
